## 写在前面：关于互联网开源精神

互联网诞生之初，最珍贵的东西不是网线与服务器，而是一种朴素的信念：**知识应该自由流动**。

从早期学者通过 RFC 免费公开的每一页技术文档，到 Richard Stallman 呐喊出的自由软件运动；从 Linus 把 Linux 内核扔到网上任人取用，到今天 GitHub 上数以亿计的仓库——开源精神一路走来，内核从未变过：

- **开放（Open）**：把门打开，让愿意学习的人都能进来。
- **共享（Share）**：我受人惠泽，亦愿惠及他人。前人种树，后人乘凉；乘凉者亦种树。
- **协作（Collaborate）**：一个人的笔记是笔记，一千个人的笔记是一座图书馆。
- **利他（Give Back）**：不问回报地留下点什么，让后来者少走一段弯路。

每一位曾在深夜被一道雅思阅读题困住的人，都欠无数无私分享的前辈一句谢谢。这份资料库，就是对这份恩情的回应与传递——**取之于社区，还之于社区**。

如果你正在备考，愿你在这里找到需要的每一块拼图；如果你已经上岸，也欢迎把你的笔记和经验留在这里，让火种继续传递。

## 使用建议

1. **先摸底**：做一套剑桥真题（如剑 18），明确四科现状。
2. **打基础**：词汇（绿宝书/807）+ 语法（Grammar in Use）贯穿全程。
3. **分科突破**：阅读精读剑雅真题 + 考点词；听力精听 + 807 听写；写作以 Simon 范文与顾家北词伙为骨架；口语跟练 Part 1/2/3 题库。
4. **考前模考**：严格计时，使用答题卡还原真实考试。
